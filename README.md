# Finance-and-Supply-Chain-Analysis-using-sql
# Finance and Supply Chain Analysis

This repository contains SQL-based implementations for **Finance and Supply Chain Analytics**.  
The project focuses on analyzing financial transactions, sales performance, and supply chain data to generate meaningful business insights.

Below is an overview of the key components and their functionalities.

---

## Finance Analytics

### A. Customer Codes for Croma India
This section includes an SQL query that retrieves customer codes for the **Croma India** market from the `dim_customer` table.

### B. Sales Transaction Data for Croma India (Fiscal Year 2021)
This query extracts all sales transaction records from the `fact_sales_monthly` table for **Croma (customer code: 90002002)** for the fiscal year 2021.

### C. Creation of the `get_fiscal_year` Function
A user-defined SQL function named `get_fiscal_year` is created to calculate the fiscal year based on a given calendar date.

### D. Using the Fiscal Year Function in Queries
The previously created `get_fiscal_year` function is incorporated into SQL queries to dynamically retrieve sales transaction data for a specific fiscal year.

---

## Gross Sales Reports

### Monthly Product Transactions
This report joins product information from the `dim_product` table with sales data from the `fact_sales_monthly` table to analyze monthly product-level transactions for **Croma India** in fiscal year 2021.

### Total Sales Amount
This section generates a **monthly gross sales report** for Croma India across all years by aggregating data from the `fact_sales_monthly` and `fact_gross_price` tables.

---

## Stored Procedures

### `get_monthly_gross_sales_for_customer`
This stored procedure generates a monthly gross sales report for any customer by accepting the customer code as an input parameter.

### `get_market_badge`
This stored procedure determines the **market badge (Gold or Silver)** based on the total quantity sold for a specified market and fiscal year.

## Yearly Report for Croma India

- Fiscal Year  
- Total Gross Sales amount generated by Croma in that year

## Supply Chain Analytics

### Creation of the `fact_act_est` Table
This section involves creating the `fact_act_est` table, which consolidates data from the `fact_sales_monthly` and `fact_forecast_monthly` tables to enable comparison between actual sales and forecasted values.

---

## Database Triggers

Two database triggers are implemented to automate data updates:

### `fact_sales_monthly_AFTER_INSERT`
Automatically inserts relevant records into the `fact_act_est` table whenever new data is added to the `fact_sales_monthly` table.

### `fact_forecast_monthly_AFTER_INSERT`
Automatically inserts forecast data into the `fact_act_est` table whenever new records are inserted into the `fact_forecast_monthly` table.

---

## Events

### `e_daily_log_purge`
A scheduled daily event that deletes records older than **5 days** from the `session_logs` table to maintain database efficiency.
